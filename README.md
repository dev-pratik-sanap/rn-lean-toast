# rn-lean-toast

A blazing fast, zero-config, edge-to-edge toast library for React Native.

## Installation


```sh
npm install rn-lean-toast
```


## Usage


```js
import { multiply } from 'rn-lean-toast';

// ...

const result = multiply(3, 7);
```
